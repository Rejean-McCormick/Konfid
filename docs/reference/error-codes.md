# Reason et Error Codes de référence

Les codes sont stables et machine-readable. Le texte humain peut changer/localiser.

- `IDENTITY_UNVERIFIED`
- `IDENTITY_REVOKED`
- `CALLER_NOT_TRUSTED`
- `TENANT_MISMATCH`
- `NO_MATCHING_GRANT`
- `GRANT_EXPIRED`
- `GRANT_SUSPENDED`
- `SCOPE_MISMATCH`
- `RESOURCE_CLASS_DENIED`
- `ACTION_NOT_GRANTED`
- `DELEGATION_INVALID`
- `DELEGATION_CHAIN_TOO_DEEP`
- `AUTH_ASSURANCE_INSUFFICIENT`
- `AUTH_TOO_OLD`
- `RISK_TOO_HIGH`
- `RISK_STATE_UNKNOWN`
- `POLICY_UNAVAILABLE`
- `REQUIRED_OBLIGATION_UNSUPPORTED`
- `APPROVAL_REQUIRED`

- `SELF_APPROVAL_FORBIDDEN`
